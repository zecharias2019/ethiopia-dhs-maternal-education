# Replication Package: Maternal Education and First-Born Infant Mortality in Ethiopia

This repository contains the full replication code for:
> **"Maternal Education and First-Born Infant Mortality: Evidence from Ethiopia"**

## Data Access & Licensing
The microdata used in this study originate from the **2016 Ethiopian Demographic and Health Survey (DHS)** Individual Women's Recode file (`ETIR71FL.DTA`).

Under the DHS Data Use Agreement, raw microdata cannot be redistributed by third parties. Registered researchers can obtain access at no cost directly from the DHS Program:
1. Register at [dhsprogram.com](https://dhsprogram.com).
2. Request access to the 2016 Ethiopia DHS Individual Recode (`ETIR71FL.DTA`).
3. Download and place `ETIR71FL.DTA` into the `data/raw/` directory of this folder.

## Repository Structure
```text
├── code/                   # All Stata .do files (00_config.do, master.do, etc.)
├── data/
│   ├── raw/                # Place ETIR71FL.DTA here (git-ignored)
│   └── derived/            # Processed analysis files generated by build code
├── output/
│   ├── figures/            # Output PNG figures (Figures 1–6)
│   └── tables/             # Output Excel/XLS tables (Tables 1, S1–S10)
├── master.do               # Master execution script
└── README.md
```

## Replication Instructions
1. Open Stata (version 15 or higher required).
2. Change the working directory to the root of this repository.
3. Run `master.do`. The script will automatically verify required Stata packages (`ivreg2`, `coefplot`, `iebaltab`, `plausexog`), build the analytical dataset, and reproduce all figures and tables in the `/output/` folder.
